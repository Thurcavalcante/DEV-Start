# Avaliação de expressões no console

Seja bem-vindo! Nesta aula, vamos tratar do seguinte assunto: Avaliação de expressões no console.

```js
let ano = 2000;
console.log(ano + 8);
```

```js
console.log("Olá, mundo"); // imprime "Olá, mundo"
console.log(4 + 6); // imprime 10
```

## Notas

- Quando aparece uma expressão no código, o JavaScipt executa algumas etapas intermediárias para avaliar o valor da expressão.
- A função **console.log()** recebe uma expressão como parâmetro.
- Uma expressão produz um **valor**, e pode ser usada em qualquer lugar onde um valor seja esperado.
