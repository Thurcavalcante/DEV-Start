# Funções com parâmetros

Seja bem-vindo! Nesta aula, vamos tratar do seguinte assunto: Funções com parâmetros.

## Função com parâmetro

```js
function transformaEmMinusculas(nome) {
  return nome.toLowerCase();
}
```

## Função com mais de um parâmetro

```js
function soma(a, b) {
  return a + b;
}
```

> Atenção aos `()` e `{}`

## Notas

- Os parâmetros da função ficam dentro dos parênteses.
- Quando você tem mais de um parâmetro, é obrigatório separá-los com um caracte de vírgula.
