# Funções com condicional if

Seja bem-vindo! Nesta aula, vamos tratar do seguinte assunto: Funções com condicional if.

```js
function mostraMensagemDeVoto(idade) {
  if (idade >= 16) {
    return "Você pode votar";
  }
}
```

## Notas

- Um erro comum é esquecer de inserir as `chaves de fechamento`, quando há uma condição `if` dentro de uma função. Tome cuidado com isso!
- Toda vez que você abrir chaves, lembre-se de que precisará fechá-las.
