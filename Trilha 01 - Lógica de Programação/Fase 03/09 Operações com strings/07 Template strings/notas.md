# Template Strings

String normal

```js
let cidade = "Goiânia";
```

Template String

```js
let cidade = `Goiânia`;
```

## Notas

- É possível definir strings com o caractere d ` crase (``) ` em vez de `aspas ("")`.
- As strings definidas com o caractere de crase são chamadas de `template strings`.
- Ao criar uma string, ela deve começar e terminar com aspas, ou então começar e terminar com o caractere de crase. Não misture os dois.
