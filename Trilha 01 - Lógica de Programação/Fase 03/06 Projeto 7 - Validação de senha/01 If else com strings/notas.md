# If/else com strings

Comparação entre duas Strings

```js
let nome = "Simone";
if (nome === "Simone") {
  // o nome é Simone
} else {
  // o nome NÃO é Simone
}
```

Comparação se a palavra é maior ou igual a 3

```js
let nome = "Simone";
if (nome.length >= 3) {
  // o nome tem 3 caracateres ou mais
} else {
  // o nome tem menos de 3 caracateres
}
```
