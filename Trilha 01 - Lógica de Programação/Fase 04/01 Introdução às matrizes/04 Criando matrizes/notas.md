# Criando matrizes

```js
let notas = [8, 6, 9, 5, 7]; // Isso funciona
```

> Cada número que é adicionado na matriz é chamado de `item da matriz`.

Para armazenar idades

```js
let idades = [18, 23];
```

Para armazenar anos

```js
let anos = [2006, 2010, 2014, 2018];
```

Para armazenar uma idade

```js
let idades = [20];
```

## Notas

- Este é um exemplo de uma matriz que representa duas idades: `let idades = [18, 23]`.
- Os elementos dentro da matriz Criando matrizessão chamados de `itens`.
- As matrizes são indicadas por `[]`, e os itens da matriz ficam entre esses colchetes.
- Cada item da matriz é separado por uma `vírgula`.
