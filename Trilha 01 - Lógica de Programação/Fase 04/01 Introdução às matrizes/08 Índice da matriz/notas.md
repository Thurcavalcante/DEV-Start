# Índice da matriz

```js
let notas = [5, 3, 8];
notas[0]; // o PRIMEIRO item retorna 5
notas[1]; // o SEGUNDO item retorna 3
notas[2]; // o TERCEIRO item retorna 8
```

Para acessar o primeiro item, índice 0;
Para acessar o segundo item, índice 1;
E assim por diante.

## Notas

- Para `acessar um item` de uma matriz, você deve escrever o nome da matriz, seguido pelo índice
- O `índice` é o número que representa a posição do item dentro da matriz
- O índice da matriz `começa em 0`
- Por exemplo, considerando a matriz notas:
- - a) para acessar o primeiro item da matriz, escreva: `notas[0]`
- - b) para acessar o segundo item da matriz, escreva: `notas[1]`
